## Dataset Descriptions

### `antioxidant13.csv`

**How it is created**

Generated from `antioxidant12.csv` by filtering the potency category corresponding to high antioxidant activity (`Category = Bajo`). Creation script: `ensayo58.py`.

**What it represents**

High-activity subset extracted from the IC50 processed dataset. Lower IC50 values correspond to higher antioxidant potency, so this dataset contains the most potent compounds. It serves as the base dataset for high-potency QSAR modeling branches.

**Typical columns**

- `Smiles`
- `Log10 Value (nM)`
- `Category`
- Additional subcategory labels generated by downstream scripts

---

### `antioxidant14.csv`

**How it is created**

Derived from `antioxidant13.csv`. The high-activity dataset is further stratified into three potency bins using quantile-based splitting (`pandas.qcut(q=3)`). Creation script: `ensayo75.py`.

**What it represents**

The high-activity dataset split into terciles to support subcategory-specific QSAR modeling workflows.

---

### `antioxidant15.csv`

**How it is created**

Generated from `antioxidant12.csv` by selecting the medium-activity subset (`Category = Medio`), then stratified into four potency bins using quantile-based splitting (`pandas.qcut(q=4)`). Creation script: `ensayo80.py`.

**What it represents**

Medium-activity IC50 dataset split into four potency subcategories, used for targeted QSAR model training.

**Key branching column:** `Subcategory`

---

### `antioxidant18.csv`

**What it represents**

A later-stage processed dataset used by the modeling workflow in `ensayo171.py`. Unlike datasets 13–15, this dataset belongs to a **low-activity modeling branch**. These compounds generally exhibit higher IC50 values, indicating lower antioxidant potency.

**Confirmed usage:** `ensayo171.py`

---

### `antioxidant19.csv`

**What it represents**

Contains antioxidant compounds collected from ChEMBL, used as a reference dataset for antioxidant activity analysis, chemical annotation, and external validation workflows within the QSAR project.

The dataset combines chemical, experimental, and bibliographic information, including reported activity values for endpoints such as IC50 and EC50, together with normalized and log-transformed activity variables.

This dataset serves as a support resource for:
- Antioxidant reference compound identification
- External QSAR validation workflows
- ChEBI annotation analyses
- Comparison against Cannabaceae-derived compounds

**Related scripts**

| Script | Role |
|---|---|
| `ensayo331.py` | ChEBI annotation |
| `ensayo332.py` | ChEBI ontology summary analysis |
| `ensayo348.py` | Prediction vs experimental validation |
| `ensayo349.py` | External validation and comparative analysis |

**Typical columns**

| Column | Description |
|---|---|
| `Molecule ChEMBL ID` | ChEMBL identifier |
| `Molecule Name` | Compound name |
| `Smiles` | Molecular structure |
| `Standard Type` | Assay endpoint type (e.g., IC50, EC50) |
| `Standard Relation` | Relation operator |
| `Standard Value` | Reported activity value |
| `Standard Units` | Units of measurement |
| `pChEMBL Value` | Normalized pChEMBL activity |
| `Assay Description` | Description of the assay |
| `Assay Type` | Assay category |
| `Target Name` | Biological target |
| `Target Organism` | Organism of origin |
| `Document Journal` | Source journal |
| `Document Year` | Publication year |
| `Normalized Value (nM)` | Standardized activity value |
| `Log10 Value (nM)` | Log-transformed activity |
| `Potencia` | Qualitative potency classification |

**Key columns for downstream analyses:** `Molecule Name`, `Smiles`, `Standard Type`, `Standard Value`, `Standard Units`, `pChEMBL Value`, `Assay Description`, `Normalized Value (nM)`, `Log10 Value (nM)`, `Potencia`

> **Note:** Some columns may contain missing values depending on original ChEMBL data availability. `Normalized Value (nM)` and `Log10 Value (nM)` are standardized variables used for comparative analyses and external validation. `Potencia` represents the final qualitative potency classification generated during the internal processing workflow.
